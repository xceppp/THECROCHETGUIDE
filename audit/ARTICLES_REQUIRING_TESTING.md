# Articles requiring a physical sample

A page is listed here only when its own text says the project was not made, not fitted, or only checked as written. `where-to-find-free-crochet-patterns` mentions that rule while describing other pages. It is not itself an untested project, and it is not listed.

Class A means the page has a written stitch sequence and says it was not yarn-tested. The arithmetic was not re-proven in this pass except for the fall leaf, which still adds up on paper (chain 9, 17 stitches around) and has still not been crocheted.

Class B means the text is untested and this pass could not confirm a complete stitch sequence. None remain after the fall leaf was read in full.

Class C means the page is an untested small project that overlaps other pages. It is not ready to be called a reliable pattern. It was not merged.

No class is "physically tested." There is no sample log in the repository.
