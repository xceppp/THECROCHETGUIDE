# Article 17 — How to Crochet a Spider (and Web)

- Slug: `how-to-crochet-a-spider-and-web`
- Halloween set · category: skills · `howTo: true`
- 3 images

Seasonal palette: **black** yarn for the spider, **pale grey** for the web.
Everything else in the house style is unchanged.

Black yarn has the opposite problem to white: it swallows stitch definition.
Every prompt here asks for strong raking light so the stitches stay readable.

All three are process or component shots. No finished hanging decoration, per
the `/disclosures` promise about generated images of finished objects.
