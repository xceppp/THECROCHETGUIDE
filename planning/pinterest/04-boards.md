# Pinterest board mapping

Primary board is where the pin is published. A secondary board is only for a later save if the pin is genuinely useful there. Do not post the same image to both boards on the same day.

Crochet Basics is not a separate board. Skill and chart pages sit on Beginner Crochet, and the low-scoring ones stay off the 30-day calendar.
